⚙️ Cómo funciona

1
🏠 Proyecto

Crea un proyecto nuevo o selecciona uno existente. Se guardan automáticamente como JSON.

2
📋 Exámenes

Añade exámenes con nombre, número de alumnos y estudio (ciclo formativo).

3
🏫 Aulas

Define aulas con capacidad y franjas de disponibilidad por fecha y hora.

4
🧠 Generar

El solver CP-SAT asigna todo respetando restricciones y genera múltiples opciones.

5
🔀 Elegir opción

Selecciona entre hasta 5 calendarios alternativos generados automáticamente.

6
📅 Calendario

Abre el HTML en el navegador e imprime como PDF con un solo clic.

🔒 Restricciones del solver

  • Cada examen se asigna a exactamente una (franja, aula)
  • Exámenes del mismo estudio no pueden coincidir en la misma franja
  • Alumnos asignados ≤ capacidad del aula en cada franja
  • Aula solo disponible en sus franjas permitidas
  • Objetivo: minimizar el número de franjas utilizadas
  • Generación de opciones diversas mediante restricciones de bloqueo

📦 Requisitos

Solo necesitas Python 3.11+ y dos librerías:

🐍 Python 3.11+ 🧮 OR-Tools CP-SAT ≥ 9.8 🖥️ PyQt6 ≥ 6.5
$ pip install -r requirements.txt

🚀 Ejecutar

$ python main.py

O simplemente haz doble clic en lanzar.bat (Windows).
