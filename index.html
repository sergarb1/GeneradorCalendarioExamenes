⚙️ Cómo funciona

1
🏠 Proyecto

Crea o selecciona un proyecto. Auto-guardado cada 5 min. Deshacer/Rehacer (50 estados).

2
📋 Exámenes

Añade exámenes con nombre, alumnos, estudio, profesor, color personalizado, preferencia de turno, duración en horas y ordenadores necesarios. Filtros en tiempo real. Importa/exporta JSON.

3
🏫 Aulas

Define aulas con capacidad, ordenadores y franjas; reserva con 🔒 las franjas que deban quedar vacías. Guarda/carga plantillas de horarios. Importa/exporta.

4
🧠 Generar

Configura N opciones (default 5). Validación previa de coherencia de datos. Barra de progreso mientras el solver CP-SAT trabaja. Genera opciones diversas automáticamente.

5
🔒 Bloquear y regenerar

Pulsa 🔓 junto a un examen (o 🔒 Bloquear visibles para hacerlo en bloque) para fijarlo a su franja/aula. Pulsa "Regenerar con bloqueos" y el solver recoloca el resto manteniendo las fijas. Barra de progreso mientras calcula. Exámenes bloqueados con borde dorado.

6
🔀 Explorar y comparar

Cambia entre opciones, alterna vista detalle/completa, compara dos opciones lado a lado con QSplitter.

7
📤 Exportar

Exporta a HTML imprimible, Word (.docx), Markdown (.md), CSV con cabeceras o JSON autocontenido (todas las opciones + bloqueos). Arrastra exámenes entre franjas para reasignarlos. El proyecto se guarda automáticamente cada 5 minutos.

🔒 Restricciones del solver

  • Cada examen se asigna a exactamente un bloque: su franja de inicio más las franjas consecutivas que cubren su duración (mismo día, encadenadas sin huecos)
  • Exámenes del mismo estudio no pueden solaparse en ninguna franja
  • Exámenes del mismo profesor no pueden solaparse en ninguna franja (incluso entre distintos estudios)
  • Suma de alumnos en cada (franja, aula) ≤ capacidad del aula
  • Suma de ordenadores en cada (franja, aula) ≤ ordenadores del aula
  • Aula solo disponible en sus franjas permitidas; las franjas reservadas no se usan y rompen las cadenas de duración
  • Objetivo: minimizar el número de franjas utilizadas
  • Preferencia de turno (mañana/tarde) como penalización blanda (×100)
  • Generación de opciones diversas mediante restricciones de bloqueo incrementales
  • Las asignaciones bloqueadas por el usuario se fijan como restricciones duras al regenerar

📅 Vista de calendario

El calendario generado ofrece múltiples formas de visualizar y exportar los resultados:

  • Selector de opciones — Cambia entre las N alternativas generadas sin perder ninguna
  • Vista detalle — Tarjetas individuales por examen con color, turno, profesor y aula
  • Vista completa — Tabla resumen con todos los exámenes de cada franja; los que continúan aparecen marcados con ↳
  • Bloqueo de asignaciones — 🔓/🔒 para fijar un examen, o 🔒 Bloquear visibles para fijar todos los filtrados, y regenerar manteniéndolos
  • Comparativa — Dos opciones en paralelo con QSplitter para comparar distribución
  • Exportar HTML — Imprimible con colores por estudio y leyenda de códigos
  • Exportar Word / MD / CSV — Documentos .docx, Markdown y CSV con tabla de asignaciones
  • Exportar / Importar JSON — Calendario autocontenido con todas las opciones y 🔒 bloqueos, para reabrirlo tal cual en otro equipo
  • Menú contextual — Clic derecho sobre un examen: editar, mover, bloquear o eliminar
  • Drag & drop — Arrastra exámenes entre franjas para reasignarlos con bloqueo automático
  • Filtro en calendario — Busca exámenes por nombre o estudio dentro del calendario

⏳ Indicador de carga

Cuando el solver CP-SAT está trabajando, la interfaz muestra una barra de progreso indeterminada y el botón de generar se deshabilita para evitar pulsaciones accidentales. Funciona tanto en generación inicial como al regenerar con bloqueos. Al terminar (éxito o fallo), se restaura el botón y se oculta la barra.

📦 Requisitos

Solo necesitas Python 3.11+ y tres librerías:

🐍 Python 3.11+ 🧮 OR-Tools CP-SAT ≥ 9.8 🖥️ PyQt6 ≥ 6.5 📄 python-docx ≥ 1.2
$ pip install -r requirements.txt

🚀 Ejecutar

$ python main.py

O simplemente haz doble clic en lanzar.bat (Windows).
